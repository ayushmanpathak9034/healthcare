# Swasthya Setu 2.0

> One Health Journey. One Intelligent Health Record.

Swasthya Setu is an AI-powered healthcare navigation and care-coordination platform designed to connect patients, doctors, hospitals, referrals, and longitudinal health records.

## Hackathon

HackShift — IIIT Delhi

## Core Features

- Voice-first multilingual patient intake
- AI-assisted clinical case-sheet generation
- Doctor-in-the-loop validation
- Smart doctor recommendation
- Smart hospital recommendation
- Digital referral workflow
- Hospital accept/decline workflow
- Unified longitudinal health timeline
- Privacy-focused encrypted case data
